02 / Two distinct engineering tracks

The live model.
The research question.

I led model design, training and evaluation. The bundled application and the final research ensemble have different input contracts and vocabularies.

Bundled application

179isolated-sign classes

MediaPipe → BiLSTM

16-frame windows of 156 hand features feed a recurrent model with temporal attention.

Designed around the live interaction

Final research ensemble

226isolated-sign classes

Four complementary streams

32 RGB frames, RTMW/RTMPose features and validation-selected ensemble weights. The official held-out test result was 94.17% Top-1.

Offline evaluation · weights frozen before testing
