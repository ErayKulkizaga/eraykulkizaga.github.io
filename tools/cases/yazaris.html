02 / A deliberately focused first product

Built around a wholesaler's
own catalog.

The initial product scope focuses on packaging and cleaning wholesalers in Kahramanmaraş. An operator brings a Turkish message; the system helps turn it into an inspectable order draft.

The intended first workflow ends with human approval and a previewed CSV/XLSX export. Direct ERP delivery, WhatsApp integration and multimodal input are later stages.

03 / Engineering judgment

A plausible answer
isn't enough.

The strongest part of this project is the work around the model: separating failure modes, defining evidence and deciding when an answer should be withheld.

03 / Model selection

Reject unsafe drafts.
