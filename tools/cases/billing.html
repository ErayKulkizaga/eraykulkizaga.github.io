02 / Correctness under concurrency

The database
holds the boundary.

Quota writes

Serialize per tenant.

PostgreSQL advisory locks prevent concurrent quota checks from independently accepting the same remaining capacity.

Pricing

Keep money exact.

Prices are stored as integer micro-USD. Token categories price independently; floating-point storage is avoided.

Background work

Claim jobs explicitly.

Workers use FOR UPDATE SKIP LOCKED to claim alert jobs and apply bounded retries.

Checkout redirects do not grant subscription access. State changes follow signature verification and event deduplication.

A stale-event guard prevents older subscription events from overwriting a newer state. The capstone keeps billing scope limited to test-mode integration.
